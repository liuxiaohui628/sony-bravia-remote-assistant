## 二、遥控器

### 型号

索尼 **标准语音遥控器**（Standard Remote with Voice），随 XR-65X90J 附赠。

外形特征：

- 黑色细长条，长约 19 cm，宽约 4.5 cm
- 表面磨砂塑料，按键为软胶材质
- 顶部有一个圆形方向键区，中间是确认键
- 底部有麦克风开孔（语音键按下时拾音）
- 靠蓝牙连接（不是红外），首次需配对

### 按键布局（从上到下）

```
┌─────────────────────────┐
│  ⏻      TV      🎬      │  电源 / 电视键 / 视频键
├─────────────────────────┤
│         ┌─────┐         │
│    ◁    │ OK  │    ▷    │  方向键 + 确认
│         └─────┘         │
│         △     ▽          │
├─────────────────────────┤
│   ⌂     ←      i+       │  主页 / 返回 / 屏显
├─────────────────────────┤
│  ＋ VOL        ＋ CH    │  音量 / 频道
│  －            －       │
├─────────────────────────┤
│    🔇        INPUT      │  静音 / 信号源
├─────────────────────────┤
│   Netflix   GooglePlay  │  应用快捷键
├─────────────────────────┤
│      🎤  （语音键）      │  麦克风
└─────────────────────────┘
```

### 本项目改造的 5 个按键

| 按键 | 物理位置 | 原始功能 | 改造后 |
|---|---|---|---|
| **语音键** 🎤 | 最下方 | 唤起索尼语音搜索 | 长按说话 → 自建语音助手 |
| **电视键** TV | 顶部左侧 | 切到电视频道 | 短按开影视仓 / 长按 2 秒选应用 |
| **视频键** 🎬 | 顶部右侧 | 切到视频输入 | 短按开云视听 / 长按 2 秒选应用 |
| **屏显键** i+ | 中部右侧 | 显示信号信息 | 同时切换二维码面板 |
| **主页键** ⌂ | 中部左侧 | 回主页 | 长按 2 秒清理后台 + 彩带 |

### 键码对照

```java
KEYCODE_SEARCH = 84    // 语音键
KEYCODE_TV     = 170   // 电视键
KEYCODE_VIDEO  = 203   // 视频键
KEYCODE_INFO   = 165   // 屏显键
KEYCODE_HOME   = 3     // 主页键
KEYCODE_BACK   = 4     // 返回键
```

抓取方法（在电视上执行，然后按遥控器）：

```bash
adb logcat -c && adb logcat | grep "KEYDOWN code="
```

## 三、为什么这些改造能生效

| 前提 | 说明 |
|---|---|
| 遥控器走蓝牙 | 按键事件进入 Android 输入系统，可被无障碍服务拦截（红外遥控不行） |
| 系统是 Android TV 10 | 支持 `AccessibilityService` 的按键过滤（Android 6+ 才有） |
| 有 ADB 调试权限 | 用于安装 APK 和授予权限（首次需在电视上开启「开发者选项」） |
| 有 root（可选） | 仅 AirPlay 需要，语音/按键/二维码都不需要 root |

### 不需要 root 就能做的事

- 拦截 5 个按键
- 语音识别与指令执行
- 悬浮窗（HUD、二维码、光标、彩带）
- 内置 HTTP 服务
- 手机遥控

### 需要 root 才能做的事

- AirPlay 投屏（需 `setenforce 0`）
- 修改系统默认应用
- 卸载系统预装应用
