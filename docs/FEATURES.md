# 功能清单

按「按键 → 行为 → 技术细节」逐条列出。所有功能均在 Sony BRAVIA XR-65X90J 实机验证。

---

## 一、按键功能

### 1. 语音键（KEYCODE_SEARCH / 84）

| 操作 | 行为 |
|---|---|
| 按住 | 立即开始录音，200ms 后显示 HUD |
| 松手（已有文本） | 立刻用已有文本匹配指令并执行，不等最终结果 |
| 松手（无文本） | 保持 HUD 短暂可见，等最终结果 |
| 松手后 1.2 秒 | 无论回调正常与否，强制收起 HUD |

**HUD 表现**：

- 文字胶囊：识别文本实时滚动显示，最多 5 行
- 麦克风胶囊：实心窄长麦克风 + 左右各 7 根声波柱
- 声波柱：每根独立相位抖动，识别出新词时跳动一次
- 背景光晕：6 色（蓝/紫/粉/橙/青绿/青）沿底部均匀分布，占据屏幕下方约 30%

**识别结果处理优先级**：

1. 当前有输入框焦点 → 填入输入框
2. 匹配到指令 → 执行（打开应用 / 调音量 / 搜索等）
3. 都不匹配 → 仅在 HUD 上显示文本

### 2. 电视键（KEYCODE_TV / 170）

| 操作 | 行为 |
|---|---|
| 短按（<2 秒） | 打开当前绑定的应用（默认影视仓） |
| 长按 0.2 秒 | 中央出现圆形倒计时环 |
| 长按满 2 秒 | 打开应用选择器 |
| 长按中途松手 | 取消，不执行任何动作 |

**特殊情况**：已在绑定应用内时，短按无任何响应（不闪屏、不重启、不弹提示）。

### 3. 视频键（KEYCODE_VIDEO / 203）

与电视键完全一致，默认绑定「云视听小电视」。

### 4. 屏显键（KEYCODE_INFO / 165）

| 操作 | 行为 |
|---|---|
| 点按（面板隐藏时） | 二维码面板从底部滑入 |
| 点按（面板显示时） | 面板向下滑出 |

**不拦截原生行为**：原生时间插件仍会同时出现/消失。

**手动模式**：由屏显键唤出的面板不会被输入法状态自动隐藏，必须再按一次屏显键才收起。

### 5. 主页键（KEYCODE_HOME / 3）

| 操作 | 行为 |
|---|---|
| 短按 | 系统默认回主页 |
| 长按 2 秒 | 清理后台应用 + 粉色纸屑彩带特效 |

**特殊处理**：输入法挡屏时按主页，先关键盘再回主页（避免键盘残留半屏）。

## 二、手机端功能（扫码后网页）

### 1. 远程输入

- 页面加载时输入框为空，不读取电视现有内容
- 输入停顿 280ms 后自动推送到电视，无需点发送
- 电视端若有输入框焦点，文字直接填入（覆盖模式）

### 2. 触摸板

| 手势 | 电视端 |
|---|---|
| 单指滑动 | 光标按 2.6 倍位移跟随 |
| 单指轻点（<320ms 且位移 <12px） | 在光标位置单击 |
| 单指长按（>550ms 未移动） | 在光标位置长按（900ms 按住） |
| 双指上下滑 | 页面滚动，距离 = 手机位移 × (电视屏高/700) |
| 停止操作 1 秒 | 光标淡出至 25% 透明度 |

### 3. 导航键

底部三个按钮，SVG 图标：

- ◀ 圆角三角 → `GLOBAL_ACTION_BACK`
- ○ 空心圆环 → `GLOBAL_ACTION_HOME`
- ■ 实心圆角方块 → `GLOBAL_ACTION_RECENTS`

### 4. 页面约束

- 禁止文本选中（`user-select:none`，输入框除外）
- 禁止双指缩放（`user-scalable=no` + `touch-action:manipulation`）
- 禁止长按弹菜单（`-webkit-touch-callout:none`）
- 页面固定高度不滚动，输入框内部滚动

## 三、系统级能力

### 语音指令集

| 类别 | 示例 |
|---|---|
| 应用启动 | 打开影视仓、启动哔哩哔哩 |
| 音量 | 调到 30、音量加、静音、取消静音 |
| 全局导航 | 主页、返回、最近任务、通知、打开设置 |
| 影视搜索 | 我想看蜘蛛侠、搜索流浪地球、找一下繁花 |
| 投屏 | 打开屏幕镜像、打开隔空播放 |
| 卸载 | 卸载 XX |

### 应用管理

- 应用选择器列出所有 `LEANBACK_LAUNCHER` 应用
- 选择结果持久化到 SharedPreferences
- 下次短按立即生效

## 四、稳定性设计

| 机制 | 作用 |
|---|---|
| 识别器忙重试 | `ERROR_RECOGNIZER_BUSY` 时 180ms 后重试一次 |
| 引擎心跳 | 启动后 1 秒无 `onReadyForSpeech` 则销毁重建 |
| 连按保护 | 上一轮未结束时先保存已有文本，避免丢字 |
| HUD 兜底 | 松手后 1.2 秒强制收起 |
| 倒计时锁 | 长按期间忽略其他按键，防重复触发 |
| 前台判断 | 已在目标应用内不重复启动 |
