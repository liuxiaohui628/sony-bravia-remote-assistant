# 需求清单

按实际开发顺序记录，每条需求都对应到已实现的功能。可作为复刻此项目的路线图。

---

## 阶段一：语音输入基础

| # | 需求 | 实现 |
|---|---|---|
| 1 | 遥控器语音键能唤起录音 | 拦截 `KEYCODE_SEARCH`(84)，调 `SpeechRecognizer` |
| 2 | 说话时出现 Siri 风格动画 | 自绘 HUD：文字胶囊 + 麦克风胶囊 + 流体光晕 |
| 3 | 识别结果填入输入框 | `ACTION_SET_TEXT` 覆盖写入 |
| 4 | 说话内容能当指令执行 | 关键词匹配（打开应用/音量/导航/搜索） |

## 阶段二：HUD 视觉打磨

| # | 需求 | 实现 |
|---|---|---|
| 5 | 麦克风图标要现代感 | 5 款方案中选「实心窄长」款（宽:高 ≈ 0.67） |
| 6 | 声波要有强弱变化 | 7 根独立柱 + 相位抖动，识别出新词时脉冲 |
| 7 | 光晕颜色均衡 | 6 色均匀分布（蓝/紫/粉/橙/青绿/青） |
| 8 | 光晕不要盖住内容 | 半径限制在底部 30%，透明度可调档 |
| 9 | 松手后无文本不要转空圈 | 有文本才转 loading，无文本直接收起 |

## 阶段三：稳定性（高频踩坑）

| # | 需求 | 实现 |
|---|---|---|
| 10 | 连续快速操作时呼不出来 | 取消/重启分离 120ms + 识别器忙重试 + 引擎心跳检测 |
| 11 | 响应太慢（1-2 秒） | 松手即用已有文本执行，不等最终结果 |
| 12 | 松手偶尔不消失 | 加 1.2 秒绝对兜底强制收起 |
| 13 | 快速连按丢字 | 连按前先保存上一轮文本 |
| 14 | 录音权限被系统收回 | 记录 `code=9` 的排查方法与授权命令 |

## 阶段四：自定义按键

| # | 需求 | 实现 |
|---|---|---|
| 15 | 电视键/视频键短按开指定应用 | `KeyPrefs` 存储绑定，`launchIntent` 启动 |
| 16 | 长按弹出应用选择器 | 2 秒倒计时 → `ChooserActivity` |
| 17 | 倒计时要能看见 | 圆圈进度 + 数字 + 「N 秒后设置按键」+「松开取消」 |
| 18 | 点按不要闪一下 | 延迟 200ms 才显示倒计时 |
| 19 | 长按期间不要重复触发 | 长按中忽略其他按键 |
| 20 | 已在前台不重复启动 | 比对包名，相同则无响应 |
| 21 | 长按主页清理后台 + 彩带 | `killBackgroundProcesses` + 34 片粉色彩带 |

## 阶段五：扫码输入

| # | 需求 | 实现 |
|---|---|---|
| 22 | 输入法左侧空白处放二维码 | 悬浮窗覆盖「搜索历史」区域 |
| 23 | 扫码后手机网页输入 | 内置 `ServerSocket` HTTP 服务（8080） |
| 24 | 输入实时同步到电视 | 停 280ms 自动 POST，无需点发送 |
| 25 | 输入框默认清空 | 页面加载不读电视内容 |
| 26 | 二维码和容器圆角一致 | `clipPath` 裁圆角位图 |
| 27 | 文字竖排 + 居中 + 大字号 | `weight=1` 撑满剩余空间，22sp |
| 28 | 输入法消失时二维码同步消失 | 绑定 `TYPE_INPUT_METHOD` 窗口事件，40ms 响应 |
| 29 | 按屏显键也能调出 | `KEYCODE_INFO`(165) 切换，手动模式不被自动隐藏 |
| 30 | 跟随输入法滑入滑出 | 260ms 滑入 / 220ms 滑出 + 淡入淡出 |

## 阶段六：手机遥控

| # | 需求 | 实现 |
|---|---|---|
| 31 | 触摸板控制光标 | 单指滑动 → 相对位移 ×2.6 |
| 32 | 轻点 = 鼠标左键 | `dispatchGesture` 60ms 点按 |
| 33 | 长按 = 长按操作 | `dispatchGesture` 900ms 按住 |
| 34 | 双指滑动 = 滚动 | 位移 × (屏高/700)，手势时长按距离计算 |
| 35 | 滚动方向要顺手 | 手指上滑 = 内容向上（看后面） |
| 36 | 光标 1 秒无操作隐藏 | 淡出至 25% 透明度 |
| 37 | 触摸板用 MacBook 深空灰 | 深灰渐变 + 顶部高光 + 底部内阴影 |
| 38 | 底部三大导航键 | SVG 圆角三角 / 圆环 / 实心方块 |
| 39 | 禁止选中和缩放 | `user-select:none` + `user-scalable=no` + `touch-action` |
| 40 | 页面固定不滚动 | `height:100%; overflow:hidden; position:fixed` |

## 阶段七：环境坑

| # | 问题 | 解决 |
|---|---|---|
| 41 | 应用网络被系统切断（EPERM） | 卸载重装重置 standby bucket |
| 42 | 重装后录音权限丢失 | `pm grant RECORD_AUDIO` |
| 43 | 重装后悬浮窗权限丢失 | `appops set SYSTEM_ALERT_WINDOW allow` |
| 44 | 手势注入无效 | 配置加 `canPerformGestures="true"` |
| 45 | 输入框焦点事件收不到 | 事件类型加 `typeViewFocused` |
